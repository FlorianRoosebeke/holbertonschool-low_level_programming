# 0x00 – Hello, World

**Objectif :** Découvrir le langage C, sa compilation et l’exécution d’un programme simple.

**Fichiers :**
- `0-preprocessor` – Inspecter le code après préprocessing.  
- `1-compiler` – Compiler un programme C sans l’exécuter.  
- `2-assembler` – Convertir le code C en assembleur.  
- `3-name` – Générer un exécutable nommé `cisfun`.  
- `4-puts.c` – Afficher une chaîne avec `puts()`.  
- `5-printf.c` – Afficher une chaîne avec `printf()`.  
- `6-size.c` – Afficher la taille de différents types.

**Compétences :** Compilation (`gcc`), préprocesseur, éditeur de liens, fonctions `puts` et `printf`.
