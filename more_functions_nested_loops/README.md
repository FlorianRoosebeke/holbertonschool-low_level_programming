# 0x03 – More functions, nested loops

**Objectif :** Approfondir les fonctions et boucles imbriquées.

**Fichiers :**
- `0-isupper.c` – Vérifier si un caractère est une majuscule.  
- `1-isdigit.c` – Vérifier si un caractère est un chiffre.  
- `2-mul.c` – Multiplier deux entiers.  
- `3-print_numbers.c` – Afficher les chiffres de 0 à 9.  
- `4-print_most_numbers.c` – Afficher les chiffres sauf 2 et 4.  
- `5-more_numbers.c` – Afficher les chiffres de 0 à 14 dix fois.  
- `6-print_line.c` – Dessiner une ligne horizontale.  
- `7-print_diagonal.c` – Dessiner une diagonale.  
- `8-print_square.c` – Dessiner un carré.  
- `9-fizz_buzz.c` – Implémenter le jeu FizzBuzz.

**Compétences :** Boucles avancées, fonctions multiples, logique conditionnelle.
