# 0x02 – Functions, nested loops

**Objectif :** Créer et utiliser des fonctions, manipuler des boucles imbriquées.

**Fichiers :**
- `_putchar.c` – Fonction pour afficher un caractère.  
- `0-putchar.c` – Afficher `_putchar`.  
- `1-alphabet.c` – Afficher l’alphabet.  
- `2-print_alphabet_x10.c` – Afficher 10 fois l’alphabet.  
- `3-islower.c` – Vérifier si un caractère est en minuscule.  
- `4-isalpha.c` – Vérifier si un caractère est une lettre.  
- `5-sign.c` – Afficher le signe d’un nombre.  
- `6-abs.c` – Retourner la valeur absolue d’un entier.  
- `7-print_last_digit.c` – Afficher le dernier chiffre d’un nombre.  
- `8-24_hours.c` – Afficher toutes les heures de la journée.  
- `9-times_table.c` – Afficher la table de multiplication de 9.  
- `10-add.c` – Additionner deux entiers.  
- `11-print_to_98.c` – Afficher tous les nombres jusqu’à 98.

**Compétences :** Fonctions personnalisées, boucles imbriquées, fonctions d’affichage.
