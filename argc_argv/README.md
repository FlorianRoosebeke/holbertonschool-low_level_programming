# 0x09 – argc, argv

**Objectif :** Utiliser les arguments de la ligne de commande.

**Fichiers :**
- `0-whatsmyname.c` – Afficher le nom du programme.  
- `1-args.c` – Afficher le nombre d’arguments.  
- `2-args.c` – Afficher tous les arguments reçus.  
- `3-mul.c` – Multiplier deux nombres passés en arguments.  
- `4-add.c` – Additionner plusieurs nombres passés en arguments.

**Compétences :** Paramètres de `main`, utilisation de `argc` et `argv`, conversion chaîne → entier (`atoi`).
